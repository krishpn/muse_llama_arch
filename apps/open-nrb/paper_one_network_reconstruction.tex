\section{Paper 1 --- Bayesian Network Reconstruction of Interbank
Exposures
(Nepal)}\label{paper-1-bayesian-network-reconstruction-of-interbank-exposures-nepal}

\textbf{Status:} core algorithms (capacitated projection, synthetic
generator, amortized training step) implemented and unit-tested; first
end-to-end synthetic validation experiment (§6/§12) running and under
active iteration --- not yet a final result. \textbf{Target venue:} ICLR
/ NeurIPS / ICAIF, ≤7 pages.

\textbf{One-line description:} Reconstruct the latent bilateral
interbank exposure matrix \(W_t\) for Nepali BFIs from NRB bulletin
data, using an SBM-structured, covariate-informed generative model with
a differentiable regulatory-constraint projection layer, amortized by a
GNN/GRU inference network.

This supersedes the earlier version of
\texttt{feature\_model\_mapping.md}, which had drifted from the actual
design (it invented a generic ``Bayesian-net structural-constraint''
layer built from accounting identities --- that was never part of the
real design and is corrected below).

\subsection{0. Problem framing and contribution to
policy}\label{problem-framing-and-contribution-to-policy}

\textbf{Problem framing (what ``the network'' means here).} We do not
pre-specify the edges of the interbank network. Instead, following the
network reconstruction literature (e.g., Squartini et al., 2018), we
treat the bilateral exposure structure as latent and infer it from
publicly observable aggregates --- balance-sheet marginals and
bank-level covariates --- within a constrained statistical framework.
Concretely: a node is a bank; a directed edge \(i \to j\) is
\(W_{ij,t}\), the exposure of bank \(i\) to bank \(j\); an edge
``exists'' when \(W_{ij,t}>0\). Neither the edge set nor the weights are
observed --- only the row/column marginals and covariates are. This is a
problem of statistical inference under partial observability, not
analysis over a topology that is already known or self-reported.
(Revisit/tighten this paragraph later --- current form is a first pass.)

\textbf{Contribution to policy.} No central bank in a
resource-constrained setting is going to mandate new bilateral exposure
reporting purely for a research exercise --- that is a costly,
politically slow regulatory change. The contribution here is that this
doesn't require that change: a usable, continuously-updatable estimate
of systemic interconnectedness is produced from data NRB (or any
similarly-resourced central bank) already publishes every month, with
zero new reporting burden. Put to a central banker directly: today there
is no way to ask ``who is exposed to whom'' or ``which banks are
structurally systemic'' --- not because the question doesn't matter, but
because answering it was assumed to require data that isn't collected.
This method shows it doesn't. It converts a previously unanswerable
supervisory question into an answerable one, cheaply, and produces a
reusable pipeline that other analyses (stress tests, contagion
simulations, Paper 2's spillover estimation) can plug into. This also
generalizes beyond Nepal: most emerging-market central banks publish the
same kind of aggregate call-report data and face the identical
constraint, so the method is a template for resource-constrained
regulators broadly, not a Nepal-specific workaround.

\subsection{1. Why this is its own
paper}\label{why-this-is-its-own-paper}

Separated from the causal/policy question (Paper 2) because the two are
methodologically unrelated: this paper's contribution is a
reconstruction method with no causal-identification content; Paper 2's
contribution is a causal-identification design that \emph{consumes} this
paper's output as a fixed input. Bundling them would force a methods
paper to carry a policy narrative it doesn't need, and vice versa.

\subsection{3. Generative model}\label{generative-model}

\begin{itemize}
\tightlist
\item
  Block membership: \(z_i \sim \text{Categorical}(\pi)\) --- (Eq. 1)
\item
  Block-pair intensity: \(\Lambda \in \mathbb{R}_{\ge0}^{K\times K}\)
  --- the SBM core
\item
  Fitness/degree-correction from covariates:
  \(\phi_{i,t} = \exp(w^\top X_{i,t})\) --- (Eq. 2)
\item
  Latent edge intensity:
  \[\lambda_{ij,t} = \Lambda_{z_i z_j} \cdot \phi_{i,t}\phi_{j,t} \cdot \exp(h_{i,t}^\top h_{j,t}) \qquad \text{(Eq. 3)}\]
\item
  Zero-inflated edge weight (most bank pairs have \emph{no} exposure):
  \[\Pr(\tilde W_{ij,t}=0) = \sigma(-\eta_{ij,t}), \qquad \tilde W_{ij,t} \mid \tilde W_{ij,t}>0 \sim \text{LogNormal}(\log\lambda_{ij,t}, \sigma^2) \qquad \text{(Eq. 4)}\]
\item
  Marginals are a \textbf{deterministic function} of \(W_t\):
  \[r_{i,t} = \sum_j W_{ij,t}, \qquad c_{j,t} = \sum_i W_{ij,t} \qquad \text{(Eq. 5)}\]
  This means the marginal constraint belongs in the \emph{architecture}
  (a hard projection), not the likelihood --- see §5.
\end{itemize}

\subsection{4. Inference network (amortized, PyG GNN +
GRU)}\label{inference-network-amortized-pyg-gnn-gru}

The encoder runs on covariates/history only --- it cannot message-pass
over \(W_t\) itself, since that would be circular (the whole point is
that \(W_t\) is unobserved).

\begin{itemize}
\tightlist
\item
  Temporal encoder:
  \(h_{i,t} = \text{GRU}_\theta([X_{i,t}; r_{i,t}; c_{i,t}], h_{i,t-1}) \qquad \text{(Eq. 6)}\),
  optionally refined by a GNN layer over an auxiliary \emph{observed}
  graph if one exists (e.g. common-sector exposure --- see §8).
  \(r_{i,t}, c_{i,t}\) (observed interbank lending/borrowing marginals
  --- real, measured aggregate fields, not derived from the model's own
  inference of the latent \(W_t\), so this doesn't violate the
  no-message-passing-over-\(W_t\) rule above) were added to the
  encoder's input after the first synthetic validation run showed block
  recovery is \emph{impossible} from \(X\) alone: \(z\) is drawn
  independently of \(X\) (Eq. 1 vs.~Eq. 2), so \(q_\psi(z)\) conditioned
  on \(X\)-history only has no signal to learn from, no matter how the
  KL term in Eq. 9 is weighted (§10).
\item
  Amortized block-assignment posterior:
  \(q_\psi(z_i \mid X_{i,1:t}, r_{i,1:t}, c_{i,1:t}) = \text{Categorical}(\text{softmax}(\text{MLP}_\psi(h_{i,t}))) \qquad \text{(Eq. 7)}\)
\item
  Pairwise decoder produces \((\eta_{ij,t}, \lambda_{ij,t})\) from
  \((h_{i,t}, h_{j,t}, z_i, z_j)\) --- full amortized variational
  posterior \(q_\psi(W_t \mid X_{1:t}, r_t, c_t)\)
\item
  Reparameterized sampling: log-normal reparam trick for the continuous
  weight, Gumbel-softmax for the discrete existence gate.
\end{itemize}

\subsection{5. Constraint-satisfaction layer (the technical core of the
paper)}\label{constraint-satisfaction-layer-the-technical-core-of-the-paper}

Differentiable \textbf{capacitated marginal projection}, via Dykstra's
alternating-projections algorithm (an ADMM-family method) onto the
intersection of three convex sets:

\[W_t = \text{Proj}_{\mathcal{R}\cap\mathcal{C}\cap\mathcal{B}}(\tilde W_t) \qquad \text{(Eq. 8)}\]

where \(\mathcal{R} = \{W : \sum_j W_{ij}=r_{i,t}\}\),
\(\mathcal{C} = \{W : \sum_i W_{ij}=c_{j,t}\}\),
\(\mathcal{B} = \{W : 0 \le W_{ij} \le \kappa K_{i,t}\ \forall j\}\) ---
i.e.~the nearest-in-Euclidean- norm matrix to \(\tilde W_t\) that
satisfies the observed marginals and the regulatory single-obligor cap
\emph{exactly}, not approximately.

\textbf{Revision note (superseded design):} an earlier draft used a
capacitated Sinkhorn/entropic-OT iteration with a \texttt{min(...)}
row-scalar clip to enforce the cap. \texttt{test\_sinkhorn.py}'s
\texttt{binding\_cap\_case} showed this doesn't implement
\(\mathcal{B}\) at all --- a single row-scalar \(u_i\) can only rescale
an entire row uniformly, so ``clip to satisfy the cap'' collapsed into
capping the \emph{row sum} (\(\sum_j W_{ij} \le \kappa K_{i,t}\)) rather
than \emph{each entry} (\(W_{ij} \le \kappa K_{i,t}\ \forall j\)) --- a
materially different, and wrong, constraint (total interbank activity
vs.~concentration to any one counterparty). Plain (uncapped)
Sinkhorn/IPF is still used, unmodified, as the classical
Gandy-Veraart/RAS baseline in §7/§12 --- that comparison never needed
the cap in the first place, so it's unaffected by this fix.

References: Cuturi (2013) entropic OT (for the uncapped baseline); Boyle
\& Dykstra (1986) for the alternating-projection algorithm; Mena et
al.~(2018) Gumbel-Sinkhorn (unrelated to this layer --- that's the
discrete existence gate, Eq. 4). Flagged explicitly as ``the one
genuinely nontrivial implementation piece'' in the design discussion ---
this is the part most likely to need real engineering effort, not the
GNN/GRU scaffolding around it.

\textbf{Correction vs.~the earlier \texttt{feature\_model\_mapping.md}:}
there is no ``Bayesian-net structural-constraint edge'' tying
\texttt{TOTAL\ Liabilities\ =\ TOTAL\ ASSETS} or \texttt{Net\ Profit}
into the graph. That was never part of this design. The accounting
identities in the raw NRB statements are a \textbf{data-quality
cross-check} on the extractor (do the reported totals reconcile?), not a
component of the generative model or the constraint layer.

\subsection{6. Training objective}\label{training-objective}

\[\mathcal{L} = -\mathbb{E}_q[\log p(W_t^{\text{true}})]_{\text{synthetic only}} + \beta_t\,\text{KL}(q_\psi(z)\,\|\,p(z)) + \lambda_{\text{smooth}}\sum_t \|W_t - W_{t-1}\|_F^2 + \lambda_{\text{reg}}\|\Lambda, w\|^2\]

\begin{itemize}
\item
  \textbf{\(\beta_t\) (KL annealing weight)}: added after the first
  synthetic validation run showed the unweighted (\(\beta_t = 1\)
  always) KL term collapsing \(q_\psi(z)\) to the uniform prior almost
  immediately (§10) --- the block-assignment posterior was getting worse
  than a trivial majority-guess baseline as training proceeded, even
  while the reconstruction likelihood kept improving via the decoder's
  direct use of \(h\). \(\beta_t\) ramps linearly \(0 \to \beta_{\max}\)
  over the first \texttt{KL\_WARMUP\_EPOCHS} epochs (standard
  \(\beta\)-VAE warm-up), giving \(q_\psi(z)\) room to latch onto block
  signal before the KL penalty pulls it toward \(p(z)\).
  \textbf{\(\beta_{\max} < 1\) (not \(1\))}: after the Eq. 6-7 encoder
  fix (feeding \(r_t, c_t\) in) made real block recovery possible ---
  block-recovery accuracy peaked at 0.85, well above the trivial
  baseline, while \(\beta_t\) was still small --- annealing all the way
  to \(\beta_t = 1\) reproduced the same collapse on a delay: accuracy
  decayed back toward/below the trivial baseline in lockstep with
  \(\beta_t\)'s climb, well before warm-up even finished. So the fix
  wasn't ramp \emph{speed}, it was the \emph{ceiling}: \(\beta_t = 1\)
  always eventually out-competes whatever reconstruction-gradient signal
  keeps \(q_\psi(z)\) informative. Current value:
  \(\beta_{\max} = 0.15\) (\texttt{KL\_BETA\_MAX} in the synthetic
  experiment script) --- \textbf{partially validated, seed-dependent}: a
  single 3000-epoch run (seed 0) held block-recovery accuracy at
  0.7578--0.7682 throughout (vs.~that run's trivial baseline of 0.7344)
  rather than decaying back down, with \(\text{KL}\) stabilizing around
  266 instead of collapsing to \textasciitilde0. A 5-seed replication of
  that same run (seeds 0--4) showed this does \textbf{not} hold up as a
  general fix: block-recovery margin over the trivial baseline was
  \(+0.0234, -0.1380, +0.1380,
  -0.1797, -0.0026\) (mean \(-0.0318\), std \(0.1148\) --- std nearly 4×
  the mean), with only 2/5 seeds beating the trivial baseline at all.
  Two distinct failure modes recur across seeds: full collapse to the
  uniform prior (\(\text{KL} \approx 0\) throughout, e.g.~seed 4), and
  confident but \emph{wrong} block assignment (\(\text{KL}\) climbs
  normally but accuracy sits below the trivial baseline, e.g.~seed 1).
  Reconstruction accuracy, by contrast, \textbf{is} robust across the
  same 5 seeds: model mean relative error beat the classical
  Sinkhorn/RAS baseline in 5/5 seeds (mean 0.4154 vs.~0.5657). See §10
  for what this means for the paper's claims.
\item
  \textbf{Synthetic data} (known ground-truth \(W_t\) from an SBM
  generator): the first term is a real supervised reconstruction loss
  --- this is the main validation evidence.
\item
  \textbf{Real data} (no \(W_t\) is ever observed): the first term drops
  out entirely. What's left is a regularized/MAP-style constrained fit,
  \emph{not} likelihood-based estimation. Evaluation on real data has to
  rely on indirect evidence: temporal stability of the recovered \(W_t\)
  sequence, and comparison against a classical baseline (§8).
\item
  \textbf{Point estimate at inference/evaluation time}: training
  (Algorithm 3) samples \(z, e, W\) via the reparameterized
  Gumbel-softmax/Gumbel-sigmoid/log-normal draws so gradients can flow,
  but reporting \(\hat W_t\) from a single such draw carries irreducible
  sampling variance even once \((\eta, \lambda, q)\) are well-calibrated
  --- this showed up empirically as a flat/noisy
  \texttt{model\_rel\_error} in the first synthetic run while the
  reconstruction likelihood term improved steadily underneath it. At
  inference/evaluation time, \(\hat W_t\) should instead be built from
  the posterior-predictive \textbf{mean} at each stage: \(q_\psi(z)\)
  itself (no Gumbel-softmax draw), \(\sigma(\eta)\) for existence (no
  Gumbel-sigmoid draw), and \(\lambda \cdot e^{\sigma^2/2}\) for
  magnitude (the log-normal mean, no reparameterized draw) --- then
  project through Algorithm 1 as usual. This is a deliberate design
  decision, not just an experiment-script detail: it governs how both
  the synthetic validation (§12) and the real-data baseline comparison
  (§7) numbers get computed.
\end{itemize}

\subsection{7. Design rationale}\label{design-rationale}

\begin{itemize}
\tightlist
\item
  \textbf{SBM over preferential-attachment/fitness models} as the sole
  structural backbone: core- periphery tiering in interbank markets is
  literally a latent-block story, so SBM is the natural fit. PA/fitness
  models (Caldarelli et al.) are cited in related work for contrast but
  not built.
\item
  \textbf{GRU, not a temporal-GNN} (EvolveGCN, TGN, etc.) for the
  temporal mechanism: deliberately the simpler choice, given the ``big
  model, small data'' risk --- roughly 50--80 institutions, at most
  \textasciitilde170 periods. A fancier temporal-GNN would be
  over-parameterized for this panel size.
\item
  \textbf{Mandatory baseline}: head-to-head comparison against
  Gandy--Veraart / RAS maximum-entropy network reconstruction, on both
  the synthetic SBM data (known ground truth) and the real panel.
  Explicit instruction from the design discussion: report honestly if
  the deep model doesn't beat the classical baseline --- don't bury a
  negative result.
\end{itemize}

\subsection{9. Known data-pipeline caveats (apply before this goes into
the
model)}\label{known-data-pipeline-caveats-apply-before-this-goes-into-the-model}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{\texttt{item\_code} collision}: confirmed by re-running
  \texttt{nrb\_extractor.py} against a real bulletin ---
  \texttt{item\_code} is not unique across the Balance Sheet's
  Liabilities and Assets sides. Both sides independently restart
  numbering at 1 (e.g.~\texttt{1\ CAPITAL\ FUND} on Liabilities
  vs.~\texttt{1\ LIQUID\ FUNDS} on Assets; same collision pattern for
  \texttt{2}, \texttt{3}, and lettered sub-items
  \texttt{a.}--\texttt{g.}). The extractor
  (\texttt{nrb\_extractor.py:197-269}, \texttt{\_extract\_rows})
  currently has no column marking which side a row is on --- that
  currently has to be inferred externally from which \texttt{TOTAL}
  block (\texttt{TOTAL\ \ \ \ Liabilities} vs.~\texttt{TOTAL\ ASSETS}) a
  row falls between on the page. \textbf{Fix needed}: add a
  \texttt{side} column to the extractor output before any join on
  \texttt{item\_code} alone, or it will silently collide liabilities and
  assets rows that share a code (e.g.~covariates 2 and 3 above, which
  both use an \texttt{item\_code\ ==\ 1} row from different sides).
\item
  Rotated bank-name header recovery (\texttt{recover\_bank\_names},
  \texttt{nrb\_extractor.py:130-171}) and the layout-mode row extraction
  are both working as validated against the real sample PDF --- no open
  bug there as of this pass.
\item
  \textbf{\texttt{item\_code} drift across eras}: the top-level code
  attached to a given labeled row is not stable over the panel's history
  --- e.g.~\texttt{LOANS\ \&\ ADVANCES} is coded \texttt{4} in some eras
  and \texttt{4.1} in others (with \texttt{BILL\ PURCHASED} shifting
  from \texttt{5} to \texttt{4.2} correspondingly). Matching must key
  off the normalized label text (and, for lettered sub-items, parent
  section), never off \texttt{item\_code} alone.
\item
  \textbf{Lettered sub-items (\texttt{a.}--\texttt{g.}) are reused
  across unrelated parent sections} (e.g.~\texttt{a.} means
  \texttt{Paid-up\ Capital} under \texttt{1\ CAPITAL\ FUND},
  \texttt{Cash\ Balance} under \texttt{1\ LIQUID\ FUNDS}, \texttt{NRB}
  under \texttt{2\ BORROWINGS}, and \texttt{Interbank\ Lending} under
  \texttt{3\ SHARE\ \&\ OTHER\ INVESTMENT} --- all in the same
  bulletin). The letter alone is not a key; a row's identity is
  (normalized label text, nearest preceding top-level/bare-number row in
  extraction order). The extractor should carry this parent link
  explicitly (a \texttt{parent\_item} or \texttt{section} column) rather
  than requiring every consumer to replay the state machine itself.
  \textbf{Side can differ across the same reused label, too}:
  \texttt{e.\ \ \ \ Others} appears under both \texttt{3\ DEPOSITS}
  (Liabilities) and \texttt{8\ OTHER\ ASSETS} (Assets) in the same
  bulletin (confirmed \texttt{Asar-2074.pdf}/NBL, 2026-10-22).
  Side-consistency checks therefore must only be enforced for the small
  set of labels the model actually reads (§8b/§8e's 8 fields) ---
  requiring every label in the bulletin to resolve to one consistent
  side will raise on this kind of legitimate, unrelated collision.
\item
  \textbf{Truncated-text duplicate rows}: some extractions clip a label
  mid-word (e.g.~\texttt{4\ LOANS\ \&} alongside the correct
  \texttt{4\ LOANS\ \&\ ADVANCES}, or \texttt{1\ CAPITAL} alongside
  \texttt{1\ CAPITAL\ FUND}) for the same \texttt{item\_code}/concept.
  Confirmed via \texttt{cut\ -d,\ -f7,8\ ...\ \textbar{}\ sort\ -u} on
  the real CSV (2026-10-22). Treat these as the same field (prefix match
  or longest-label-wins), not as missing data for the truncated variant.
\item
  \textbf{Pre-2075-era bulletins never extract a
  \texttt{TOTAL\ Liabilities} marker row at all} (confirmed against real
  \texttt{Asar-2074.pdf}, 2026-10-22) --- the Liabilities section just
  ends and the Assets section starts back at \texttt{item\_code\ "1"}
  with no boundary row to key off. Side inference needs a fallback for
  this era that doesn't depend on the marker existing: a drop back to a
  lower top-level bare-digit \texttt{item\_code} while still in the
  Liabilities state is itself the side boundary (top-level codes
  strictly increase within one side).
\item
  \textbf{Real bulletins extract row-major by line item, interleaved
  across banks} --- bank A's row for item N is immediately followed by
  bank B's row for item N, not bank A's entire sheet followed by bank
  B's (confirmed 2026-10-22; caused a live ``inconsistent side'' error
  before this was known). Side inference must replay its
  liabilities/assets state machine \textbf{per
  \texttt{(source\_file,\ bfi\_name)} bank-block}, re-sorted by original
  extraction order --- not as one shared state machine over the raw file
  order --- or one bank's \texttt{TOTAL\ LIABILITIES} marker flips the
  state for every other bank's very next row too.
\item
  \textbf{Blank value cells are dropped from extraction entirely, not
  reported as a zero.} A row with an empty value field (seen on
  optional/granular categories some banks don't report,
  e.g.~\texttt{9\ EXPENSES\ \ \ \ NOT\ WRITTEN\ OFF}) is simply absent
  from that bank/period's record, not present with value 0. Any field
  built by summing a fixed list of categories (e.g.~the \texttt{size}
  covariate, §8b) must treat a missing category as 0 explicitly rather
  than looking it up strictly --- a strict lookup wrongly drops the
  entire bank/period cell over one legitimately-absent optional row.
\end{enumerate}

decided)}\label{open-items-not-yet-decided}

\begin{itemize}
\tightlist
\item
  \textbf{\(K\) (number of SBM blocks)}: start with \(K=2\)
  (core/periphery), treat larger \(K\) as a robustness check, not the
  headline specification.
\item
  \textbf{\(\sigma^2\) (log-normal dispersion)}: learned, either
  globally or per-block --- not yet decided which.
\item
  \textbf{Venue/scope hook}: ICAIF fit is comfortable at the current
  scope (methods + real-data case study). ICLR/NeurIPS main track would
  need an added theoretical hook --- e.g.~a provable statement on how
  reconstruction uncertainty in \(\hat W_t\) propagates into coverage
  guarantees for a downstream interference estimator (which would also
  strengthen the Paper 1 → Paper 2 link). \textbf{Not resolved} ---
  needs a decision before drafting.
\item
  \textbf{Posterior collapse on the block-assignment KL term --- root
  cause identified, architecture fix plus capped KL ceiling fixes
  reconstruction but NOT block recovery reliably across seeds}: Eq. 9's
  \(\text{KL}(q_\psi(z)\|p(z))\) under the original unweighted
  (\(\beta_t = 1\) always) term collapsed to \textasciitilde0 almost
  immediately in the first synthetic validation run. A direct check
  (\texttt{argmax(q)} vs.~the synthetic ground-truth \(z\), best
  accuracy over label permutations since block labels are
  unidentifiable) confirmed this is real collapse, not just a
  small-but-harmless KL value: block-recovery accuracy \emph{fell below}
  the trivial ``always guess the majority block'' baseline
  (\texttt{max(pi)}, not \(1/K\), since \texttt{pi} is imbalanced) as
  training proceeded. This persisted even after §11 Algorithm 2's
  existence-gate fix (giving \(\eta\) a block-dependent structure via
  \texttt{eta\_block}, mirroring \(\Lambda\)) and after \(\beta_t\) KL
  annealing (linear warm-up, §6, \texttt{TrainStepConfig.kl\_beta}):
  annealing stopped block-recovery accuracy from falling \emph{below}
  the trivial baseline, but it only ever plateaued exactly at that
  baseline, never above it. Root cause: \(q_\psi(z_i)\), prior to the
  Eq. 6-7 fix, was conditioned on \(X_{i,1:t}\) alone --- but the
  generative model draws \(z_i\) (Eq. 1) and \(X_i\) (Eq. 2)
  independently, so the encoder had \emph{zero} information from which
  to ever recover \(z\) above the trivial majority-class floor,
  regardless of how the loss is reweighted. Fix: the encoder's input was
  widened to \([X_{i,t}; r_{i,t}; c_{i,t}]\) --- the observed interbank
  lending/borrowing marginals, which \emph{are} functions of \(z\)
  through \(\Lambda[z_i,z_j]\) --- matching §4's own already-stated (but
  previously unimplemented) intent of
  \(q_\psi(W_t \mid X_{1:t}, r_t, c_t)\). The first re-run with it in
  place showed block-recovery accuracy \emph{peak at 0.85} --- well
  above the trivial baseline --- confirming \(r_t, c_t\) do carry real
  block signal once the encoder can see them, but accuracy then decayed
  back toward/below the trivial baseline as \(\beta_t\) annealed toward
  \(1\): annealing to a full \(\beta_t=1\) reproduces the original
  collapse on a delay, this time by out-competing a signal that
  \emph{does} exist rather than one that never did. Mitigation: cap
  \(\beta_t\)'s asymptote at \(\beta_{\max} = 0.15 < 1\) instead of
  annealing to \(1\) (§6). A single 3000-epoch re-run with this cap
  (seed 0) held block-recovery accuracy at 0.7578--0.7682 for the entire
  run (epoch 200 through 2999), against that run's trivial baseline of
  0.7344 --- \(\text{KL}\) stabilized around 266 rather than collapsing,
  and \(\hat W_t\)'s relative Frobenius error kept improving in parallel
  (to 0.4297, vs.~baseline 0.5965). \textbf{A 5-seed replication (seeds
  0--4) showed this does NOT generalize}: block-recovery margin over the
  trivial baseline was \(+0.0234, -0.1380,
  +0.1380, -0.1797, -0.0026\) across seeds 0--4 --- mean \(-0.0318\),
  std \(0.1148\) (std nearly 4× the mean) --- with only 2/5 seeds
  beating the trivial baseline at all. Seed 0's healthy-looking run was
  not representative; on average across seeds, block recovery is
  statistically indistinguishable from (if anything slightly worse than)
  the trivial majority-guess baseline. Two distinct failure modes recur:
  full collapse to the uniform prior (\(\text{KL} \approx 0\) throughout
  --- seed 4), and confident-but-wrong block assignment (\(\text{KL}\)
  climbs to a healthy magnitude but accuracy sits \emph{below} the
  trivial baseline anyway --- seed 1). Reconstruction accuracy, in
  contrast, \textbf{is} robust across the same 5 seeds: model mean
  relative Frobenius error beat the classical Sinkhorn/RAS baseline in
  5/5 seeds (mean 0.4154 vs.~0.5657, std 0.0416 vs.~0.0257).
  \textbf{Resolved conclusion for now}: the paper's claim that ``the
  model identifies which banks are core'' is \textbf{not currently
  supported} by this architecture + hyperparameter combination --- it
  should either

  \begin{enumerate}
  \def\labelenumi{(\alph{enumi})}
  \tightlist
  \item
    be dropped in favor of the already-robust claim (``the model
    recovers \(W_t\) more accurately than the classical baseline,'' no
    block-identity claim), or (b) remain an explicit goal pending
    further work: longer training, more \texttt{BlockPosteriorMLP}
    capacity, a lower \(\beta_{\max}\), or a per-seed diagnosis of why
    seeds 1/4 fail differently from seeds 0/2. Not yet decided which
    path; revisit once real-data validation (§9/§12) is underway, since
    that may be a better use of time than chasing a synthetic-only
    metric further.
  \end{enumerate}
\end{itemize}

\subsection{11. Algorithms (pseudocode)}\label{algorithms-pseudocode}

Three algorithms, in dependency order: the capacitated projection (the
hard constraint layer, Eq. 8) is standalone and testable without the
rest of the model; the generative forward pass (Eq. 1-5, 8) samples a
synthetic \(W_t\) for validation; training (Eq. 6-9) wraps the amortized
encoder/decoder of §4 around the same projection layer. All three are
written over \emph{symbol-level} inputs (\(N\), \(K\), \(d\),
\(\kappa\), etc.) --- nothing below is a fixed dataset size or constant;
see §12 for how these get threaded through as config, not literals.

\subsubsection{\texorpdfstring{Algorithm 1 ---
\texttt{CapacitatedProjection} (Eq. 8, Dykstra's alternating-projections
algorithm)}{Algorithm 1 --- CapacitatedProjection (Eq. 8, Dykstra's alternating-projections algorithm)}}\label{algorithm-1-capacitatedprojection-eq.-8-dykstras-alternating-projections-algorithm}

\begin{verbatim}
Input:  W̃ ∈ R^{N×N}_{≥0}      raw/sampled edge weights
        r, c ∈ R^N_{≥0}        target row/column marginals (observed r_i,t, c_i,t)
        cap ∈ R^N_{≥0}         per-row obligor cap, cap_i = κ · K_i,t
        n_iters, tol           stopping criteria (n_iters counts full row→col→box
                                passes, not single-set applications)
Output: W ∈ R^{N×N}            satisfies row/col marginals and W_ij ≤ cap_i for all j,
                                exactly (up to tol), when the intersection is non-empty

 1:  W ← W̃
 2:  I_row, I_col, I_box ← zeros(N,N), zeros(N,N), zeros(N,N)   # Dykstra correction terms
 3:  for iter = 1 .. n_iters:
 4:      W_prev ← W
 5:      Y ← W + I_row
 6:      W ← Y + (r − row_sums(Y)) / N          # Proj onto {row sums = r}, broadcast per row
 7:      I_row ← Y − W
 8:      Y ← W + I_col
 9:      W ← Y + (c − col_sums(Y)) / N          # Proj onto {col sums = c}, broadcast per col
10:      I_col ← Y − W
11:      Y ← W + I_box
12:      W ← clip(Y, 0, cap)                     # Proj onto {0 ≤ W_ij ≤ cap_i}, per-row cap,
                                                   #   applied to EVERY entry in row i
13:      I_box ← Y − W
14:      if ‖W − W_prev‖ < tol: break
15: return W
\end{verbatim}

Note: unlike the superseded Sinkhorn-clip draft (see §5's revision
note), this provably converges to the \emph{exact} Euclidean projection
onto the intersection of all three constraint sets whenever that
intersection is non-empty (Boyle \& Dykstra, 1986) --- not a heuristic.
All three per-set projections (lines 6, 9, 12) are closed-form and
differentiable (the clip has the usual subgradient at the boundary, same
as a ReLU), so gradients flow through to \(\tilde W_t\) exactly as Eq. 8
requires for Algorithm 3's step 10. If the intersection is empty ---
e.g.~\(\kappa K_{i,t}\) set so tight that
\(N \cdot \kappa K_{i,t} < r_{i,t}\) for some \(i\), meaning the cap
can't physically supply the required row total even by maxing out every
entry --- this converges to a least-violation compromise instead, which
should be treated as an infeasible-cap data/parameter error, not
silently accepted (\texttt{test\_capacity\_projection.py}'s
\texttt{infeasible\_case} checks for this --- the cap itself must still
hold even when the row marginal can't be reached).

\subsubsection{\texorpdfstring{Algorithm 2 ---
\texttt{SampleSyntheticNetwork} (Eq. 1-5, 8; ground truth for
validation,
§6)}{Algorithm 2 --- SampleSyntheticNetwork (Eq. 1-5, 8; ground truth for validation, §6)}}\label{algorithm-2-samplesyntheticnetwork-eq.-1-5-8-ground-truth-for-validation-6}

\begin{verbatim}
Input:  N, K, d                 problem size (num banks, num blocks, covariate dim)
        π ∈ Δ^K, Λ ∈ R^{K×K}_{≥0}, H ∈ R^{K×K}, w ∈ R^d, σ²        generative params (drawn
                                                        from a prior or fixed per synthetic
                                                        scenario); H is the block-pair
                                                        zero-inflation logit matrix (Eq. 4),
                                                        block-structured the same way Λ is
                                                        (Eq. 3) — existence, not just
                                                        magnitude, needs a block-dependent
                                                        pattern for q_psi(z) to have any
                                                        recon-loss signal to recover it from
        X_{1:N} ∈ R^{N×d}        covariates for this period (synthetic or real)
        κ, K_cap ∈ R^N           regulatory cap inputs
Output: W_true ∈ R^{N×N}_{≥0}, r, c ∈ R^N      ground-truth network + its implied marginals

1:  for i = 1 .. N: z_i ~ Categorical(π)                      # Eq. 1
2:  for i = 1 .. N: φ_i ← exp(w^T X_i)                        # Eq. 2
3:  for i, j = 1 .. N (i ≠ j):
4:      λ_ij ← Λ[z_i, z_j] · φ_i · φ_j                        # Eq. 3 (no h_i·h_j term — no
                                                               #   history yet for a one-shot sample)
5:      η_ij ← H[z_i, z_j]; e_ij ~ Bernoulli(σ(η_ij))          # Eq. 4, block-structured same as step 4
6:      W̃_ij ← e_ij · LogNormal_sample(log λ_ij, σ²)
7:  r ← row_sums(W̃); c ← col_sums(W̃)                         # pre-projection marginals
8:  W_true ← CapacitatedProjection(W̃, r, c, κ·K_cap)           # Eq. 8 — ground truth MUST
                                                               #   also satisfy the cap, or the
                                                               #   model is validated against an
                                                               #   infeasible target
9:  return W_true, row_sums(W_true), col_sums(W_true)
\end{verbatim}

\subsubsection{\texorpdfstring{Algorithm 3 --- \texttt{TrainStep} (Eq.
6-9; amortized inference + one optimizer
step)}{Algorithm 3 --- TrainStep (Eq. 6-9; amortized inference + one optimizer step)}}\label{algorithm-3-trainstep-eq.-6-9-amortized-inference-one-optimizer-step}

\begin{verbatim}
Input:  batch of periods {X_{1:N,t}, r_t, c_t, K_t}_{t ∈ batch}, optional W_true_t (synthetic only)
        model params θ (GRU), ψ (block/decoder nets), Λ, w, σ²
        hyperparams λ_smooth, λ_reg, κ
State:  h_{i,t-1} carried across periods (GRU hidden state)
Output: loss value; updated θ, ψ, Λ, w after one gradient step

1:  for t in batch (in temporal order):
2:      for i = 1 .. N: h_{i,t} ← GRU_θ([X_{i,t}; r_{i,t}; c_{i,t}], h_{i,t-1})  # Eq. 6
3:      [optional] h_{i,t} ← GNN_refine(h_{i,t}, A_obs_t)                 # §4, §8c
4:      for i = 1 .. N: q_i ← softmax(MLP_ψ(h_{i,t}))                    # Eq. 7
5:      for i = 1 .. N: z_i ← GumbelSoftmaxSample(q_i)                    # reparameterized
6:      for i, j = 1 .. N (i ≠ j):
7:          (η_ij,t, λ_ij,t) ← Decoder_ψ(h_i,t, h_j,t, z_i, z_j)          # Eq. 3-4
8:          e_ij,t ← GumbelSigmoidSample(η_ij,t)                          # reparameterized gate
9:          W̃_ij,t ← e_ij,t · LogNormalSample(log λ_ij,t, σ²)            # reparameterized weight
10:     W_t ← CapacitatedProjection(W̃_t, r_t, c_t, κ·K_t)         # Eq. 8, Algorithm 1
11:     if W_true_t is given (synthetic branch):
12:         L_recon,t ← -log p(W_true_t | λ_t, η_t, σ²)                   # Eq. 9, first term
13:     else:
14:         L_recon,t ← 0                                                 # real data: no ground truth
15:     L_KL,t ← KL(q_ψ(z_t) ‖ p(z))
16: L_smooth ← Σ_t ‖W_t - W_{t-1}‖_F²            over consecutive periods in the batch
17: L_reg ← ‖Λ‖² + ‖w‖²
18: L ← Σ_t (L_recon,t + L_KL,t) + λ_smooth · L_smooth + λ_reg · L_reg
19: backprop L; update θ, ψ, Λ, w via optimizer step
20: return L
\end{verbatim}
